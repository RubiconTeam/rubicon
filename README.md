# Rubicon
Main addon for Rubicon. Includes all the tools for levels, characters and different game modes!

The addon by itself does not provide any game mode or Godot project files, although we provide a mania mode through the [Rubicon Mania](https://github.com/RubiconTeam/rubicon_mania) submodule that can be added alongside this one in the `addons/` folder.

Rubicon can be added to any project at any time. It does not have any dependency nor does it interfere with existing classes or addons.

## Documentation
Documentation will be worked on as soon as possible for us, and will be hosted at [here](https://docs.rubiconengine.xyz/).

## Installing
You can either add it to your repository as a submodule (recommended, as you can keep it updated this way), or directly clone the repository into your `res://addons/` folder.

To add the submodule to your project, open a terminal, cmd, powershell or git bash in your project location and run this command:
```
git submodule add --name rubicon https://github.com/RubiconTeam/rubicon addons/rubicon || git submodule update --init --recursive --remote
```
